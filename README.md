# Camper Cafe Menu

A beautifully styled, responsive, and semantic single-page web menu for a fictional cafe called **Camper Cafe**. This project showcases structured HTML5 layout techniques along with modern CSS design patterns, typography, and interactive link styling.

## 📋 Features

- **Semantic HTML5:** Built using structure-first markup tags such as `<main>`, `<section>`, `<article>`, `<address>`, and `<footer>`.
- **Responsive Layout:** Contained inside a centered menu box with fluid width structures (`width: 80%`, `max-width: 500px`) that look great on both mobile screens and desktop monitors.
- **Custom Visual Styling:** - Rich textures utilizing a background image background (`beans.jpg`) paired with a warm `burlywood` card theme.
  - Custom thematic horizontal rules (`<hr>`) styled in a deep brown tone.
- **Advanced Typography & Alignment:** Uses robust typography stacking (`Impact` with fallback `serif`) for major headings and `sans-serif` for readable text. Side-by-side positioning for flavors/desserts and their respective pricing is elegantly handled via inline-block properties.
- **Enhanced Link Behaviors & Security:** Fully styled standard state, visited, hover, and active states for user navigation, incorporating standard security protocols (`target="_blank"` paired with `rel="noopener"`).

## 🗂️ File Structures

The project contains the following operational files:

- `index.html` - Handles the full structural presentation, metadata settings, text contents, menu catalog breakdowns, and semantic sections.
- `style.css` - Custom style definitions controlling color schemes, layout constraints, typographic treatments, image alignments, and interactivity rules.

## 🚀 How to Run the Project

1. Clone or download the project files (`index.html` and `style.css`) into a single folder on your local computer.
2. Ensure both files reside in the same root folder so the `<link href="style.css" rel="stylesheet"/>` declaration resolves correctly.
3. Open `index.html` in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) by double-clicking the file or dragging it into an open window.
